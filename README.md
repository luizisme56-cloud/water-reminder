# 喝水 · 每日提醒 💧

一个极简的喝水打卡网页，打开就能用，不用装 App。

**在线使用：** https://luizisme56-cloud.github.io/water-reminder/

## 功能
- 环形进度显示今日饮水量
- 一键记录（200 / 250 / 330 / 500 / 600 ml 五种杯型）
- 可自定义每日目标、提醒时间段与提醒间隔
- 浏览器通知定时提醒
- 数据保存在本机（localStorage），不上传服务器

## 用法
1. 用手机浏览器打开链接
2. 点「分享 → 添加到主屏幕」，即可像 App 一样全屏使用
3. 在设置里开启浏览器通知，并按自己的作息调整提醒时间

## 说明
通知在页面驻留时生效。想要更强的后台提醒，可配合系统「提醒事项」的重复提醒。
